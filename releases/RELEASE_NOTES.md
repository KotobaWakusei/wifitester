# WiFiTester 2.5.1 发布说明

## 版本信息
- 版本号: 2.5.1
- 构建号: 2024
- 发布日期: 2026-10-23

### Debug 版本
- 包含调试标识，用于开发测试
- 支持工具包按需下载

### Release 版本
- 未签名（或按 keystore.properties 签名）
- 适合正式分发

## 下载链接

## 更新内容
- 新增工具包管理系统
- 支持按需下载工具包
- 设备能力检测
- 优化APK体积
- 修复已知问题

## 安装说明
1. 下载对应版本的APK文件
2. 安装到Android设备
3. 首次启动时选择需要的工具包
4. 授予Root权限以使用完整功能

## 注意事项
- 需要Root权限才能使用完整功能
- 部分设备可能不支持Wi-Fi监听模式
- 请确保从可信来源下载APK文件
